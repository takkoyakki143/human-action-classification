# 정지 이미지 기반 사람 행동 분류: ResNet18 학습 전략 비교와 오류 분석

Stanford 40 Actions 중 8개 행동 이미지(학습 640장)로, 동일한 ResNet18의 Training from Scratch / Feature Extraction / Fine-tuning을 같은 조건에서 비교하고, 오분류 분석에서 세운 가설을 근거로 개선 실험을 수행해 최종 모델을 선정하는 프로젝트입니다.

[결과 작성 예정: 최종 선택한 학습 방식, Validation Macro F1과 학습 시간, 개선 실험 결과와 판단, 최종 Test 결과]

> Stanford 40 Actions에서 8개 행동을 선정한 데이터를 활용하여, PyTorch로 이미지 분류 모델의 학습·평가와 오류 분석을 진행했습니다.

## 1. 프로젝트 개요

- **해결하려던 문제:** 사람이 찍힌 정지 이미지 한 장을 보고 8가지 행동(등반, 점프, 자전거 타기, 승마, 보트 노 젓기, 달리기, 활쏘기, 프리스비 던지기) 중 하나로 분류합니다. 클래스당 학습 이미지가 80장뿐인 상황에서 ImageNet 사전학습 지식을 어떤 방식으로 활용해야 효과적인지, 그리고 모델이 배경·여백·촬영 세션 같은 지름길이 아니라 실제 행동의 단서(자세와 도구)를 보고 판단하는지를 확인하고자 했습니다.
- **목표와 평가 기준:** 동일한 분할·전처리·평가 지표에서 세 가지 학습 방식의 성능과 학습 비용을 비교하고, 오분류 분석에 근거한 개선 실험으로 최종 모델을 선정합니다. 성능 수치보다 공정한 비교, 오류 원인 분석, 근거 있는 개선에 초점을 둡니다. 핵심 지표는 Test의 클래스 불균형(최대 2.31배)을 고려한 Macro F1이며, 모델 선택과 개선 판단은 Validation으로만 하고 Test는 최종 모델 확정 후 한 번만 평가합니다.

### 추진 배경

**정지 이미지 행동 분류는 사물 분류보다 어렵습니다.** 행동은 하나의 사물이 아니라 사람의 자세, 손에 든 도구(활, 원반, 노), 주변 장소가 함께 만드는 의미입니다. 영상과 달리 움직임 정보가 없어 점프와 달리기처럼 자세가 비슷한 행동을 구분하기 어렵고, 모델이 행동 대신 "물이 보이면 보트"처럼 배경만으로 판단하는 지름길을 배울 위험도 있습니다.

**학습 데이터가 적습니다.** Train은 클래스별 80장, 총 640장입니다. 처음부터 학습하면 과적합되기 쉬우므로, 사전학습 지식을 얼마나, 어떤 방식으로 활용할지가 핵심 질문이 됩니다.

**EDA에서 데이터 고유의 어려움을 확인했습니다.** (근거: [`01_eda.ipynb`](notebooks/01_eda.ipynb), 상세 내용은 [5. 문제 해결 과정](#5-문제-해결-과정))

- **사진 형태가 클래스마다 다릅니다.** 종횡비가 0.46~2.79로 다양하고, 등반·점프·달리기는 세로형, 승마·활쏘기·보트는 가로형이 많습니다. Center Crop은 핵심 도구를 잘라낼 수 있고, Padding은 대상을 작게 만들며 여백 모양에 사진 방향이 드러납니다.
- **작은 단서가 많습니다.** 프리스비 원반처럼 행동을 결정하는 도구가 작게 찍힌 사진이 있고, 짧은 변이 224px 미만인 저해상도 사진도 176장입니다.
- **평가 데이터가 불균형합니다.** Train·Validation은 균형이지만 Test는 클래스별로 최대 2.31배 차이가 납니다(승마 196장, 보트 노 젓기 85장).
- **같은 촬영 세션의 사진이 Train과 Test에 나뉘어 있습니다.** 동일 사진 중복은 없었지만, 같은 행사나 같은 인물을 찍은 사진이 양쪽에 있어 Test 점수가 실제 일반화 성능보다 높게 나올 수 있습니다.

### 문제 정의

> **핵심 질문:** 클래스당 80장의 적은 데이터로 정지 이미지 속 행동을 분류할 때, ImageNet 사전학습 지식을 어떤 방식으로 활용해야 가장 효과적인가? 그리고 그 모델은 배경·여백·촬영 세션 같은 지름길이 아니라 실제 행동의 단서를 보고 판단하는가?

이 질문을 세 가지 세부 문제로 나누어 해결합니다.

**① 학습 방식 비교: 사전학습을 얼마나 활용할 것인가**
같은 ResNet18을 처음부터 학습(Scratch), 사전학습 특징 추출부를 고정하고 분류기만 학습(Feature Extraction), 사전학습 가중치에서 시작해 일부 또는 전체를 다시 학습(Fine-tuning)하는 세 방식으로 학습합니다. 성능과 함께 학습 비용(Epoch, 학습 시간, 학습 가능한 파라미터 수)을 비교합니다. Scratch의 낮은 성능은 실패가 아니라 사전학습의 효과를 보여 주는 비교 기준으로 해석합니다.

**② 오류 분석: 모델은 무엇을 근거로 판단하는가**
가장 좋은 방식의 Validation 오분류를 분석하여, 학습 전에 EDA에서 세운 가설을 확인합니다.

| 가설 | EDA 근거 | 확인 방법 |
|---|---|---|
| 점프와 달리기를 혼동한다 | 정지 자세가 비슷하고, 해변 배경을 공유하는 사례가 있음 | Confusion Matrix, 오분류 사진 관찰 |
| 여백 모양을 단서로 쓴다 | 클래스별 사진 방향(세로형/가로형)이 다름 | 사진 방향별 오류 분포 |
| 작은 도구를 놓친다 | 작은 원반, 저해상도 176장, Padding으로 인한 축소 | 프리스비 Recall, 오분류 사진의 원반 크기 |
| 배경으로 판단한다 | 물·암벽·잔디 등 클래스별 전형적 배경 | 배경이 전형적이지 않은 사진의 오류 |

**③ 근거 있는 개선: 원인에 맞는 처방인가**
오분류 분석에서 가장 근거가 강한 가설을 골라 개선 실험을 수행하고(예: 작은 도구를 놓친다면 입력 해상도 상향, 과적합이라면 약한 증강), 개선 전후의 성능과 학습 비용을 비교합니다. Validation이 160장뿐이라 1장 차이가 약 0.6%p이므로, 1~2%p 차이로 개선을 단정하지 않고 가능하면 여러 seed의 평균과 변동을 함께 봅니다.

촬영 세션 사진의 영향은 모델 선택에 쓰지 않고, 최종 Test 평가 후 학습 데이터와 많이 닮은 사진과 덜 닮은 사진의 성능을 나눠 해석하는 데에만 사용합니다.

**조건:** 모델은 ResNet18(ImageNet 가중치 `IMAGENET1K_V1`)로 고정하고 입력은 이미지의 RGB 픽셀만 사용합니다. 제공된 분할을 그대로 쓰며 원본 데이터로 학습 이미지를 늘리지 않습니다. 세 방식에 같은 전처리(Resize + Padding 224×224, ImageNet 정규화)를 적용하고, 데이터 증강은 Train에만 적용합니다.

## 5. 문제 해결 과정

### 주요 접근

- **데이터:** Stanford 40 Actions 중 8개 행동(등반, 점프, 자전거 타기, 승마, 보트 노 젓기, 달리기, 활쏘기, 프리스비 던지기)의 RGB 이미지 2,031장을 사용했습니다. 제공된 분할(Train 640 / Validation 160 / Test 1,231)을 그대로 사용했으며, Train·Validation은 원본 Train, Test는 원본 Test에서 왔습니다.
- **평가 지표:** Test는 클래스별로 최대 2.31배 불균형합니다. 가장 적은 클래스(보트 노 젓기 85장)를 모두 틀려도 Accuracy는 6.9%p만 낮아지지만, Macro 지표는 약 12.5%p 낮아집니다. 이를 근거로 소수 클래스의 실패가 그대로 드러나는 Macro F1을 핵심 지표로 정했습니다.
- **전처리 기준:** 이미지 종횡비가 0.46~2.79로 다양하고, Center Crop은 클래스별 평균으로 원본 면적의 약 43~47%를 잘라내 가장자리의 노·활이 사라질 수 있었습니다. 그래서 종횡비를 유지하는 Resize + Padding을 기본 전처리로 정했습니다.
- **전처리:** 세 학습 방식 모두 같은 전처리를 사용했습니다. 모든 이미지를 RGB로 읽어 종횡비를 유지한 채 긴 변을 224로 맞추고, 남는 영역은 ImageNet 평균색(124, 116, 104)으로 채워 224×224로 만든 뒤 ImageNet 평균·표준편차로 정규화했습니다. 평균색으로 채운 영역은 정규화 후 값이 0에 가까워 모델에 추가 정보를 주지 않습니다. ### 중요한 문제와 판단: 중복 점검에서 발견한 촬영 세션 사진

- **문제·관찰:** 지각 해시(dHash)로 분할 간 중복을 점검해 유사 후보 4쌍을 찾았고, 이 중 2쌍은 Test와 학습 데이터 사이였습니다. 육안 확인 결과 4쌍 모두 구도만 비슷한 다른 사진이었습니다. 하지만 dHash는 이미지를 9×8 크기로 줄여 밝기 구조만 비교하므로, 잘라내거나 색을 보정한 중복은 놓칠 수 있습니다. "후보가 모두 오탐이었다"는 것만으로는 중복이 없다고 결론 내리기 어려웠습니다.
- **판단 근거:** 밝기 구조가 아니라 사진의 내용을 비교하는, 원리가 다른 방법으로 교차 확인이 필요하다고 판단했습니다. 또 기준값(거리 6 이하)에 따라 결과가 달라지는 문제를 피하고자, 기준값 없이 가장 비슷한 쌍부터 순위를 매겨 위에서부터 확인하는 방식을 택했습니다.
- **수행한 작업:** 사전학습 ResNet18의 특징 벡터(원본과 좌우 반전 특징의 합)로 코사인 유사도를 계산하고, Test 사진마다 가장 닮은 Train·Validation 사진을 찾아 상위 쌍을 육안으로 검토했습니다. 최근접 유사도 분포(0.72~0.95)에 1.0 근처의 독립된 무리가 없고 상위 쌍도 모두 다른 사진이어서, 동일 사진 중복은 없다는 결론을 유지했습니다.
- **판단의 변화:** 대신 dHash에서는 보이지 않던 사실을 발견했습니다. 같은 팀 유니폼, 같은 행사 티셔츠, 같은 인물의 다른 순간처럼 **같은 촬영 세션의 사진이 Train과 Test에 나뉘어** 있었습니다(프리스비·보트·자전거에 집중). 분할을 다시 나누는 것도 검토했지만, 분할은 과제의 고정 조건이고 `group_id`에도 세션 정보가 없어 근거 있는 재분할이 불가능했습니다. 세 학습 방식이 같은 분할로 평가되므로 비교의 공정성에는 영향이 없다고 판단해 분할은 유지했습니다. 대신 Test 점수가 처음 보는 장면에 대한 성능보다 높게 나올 수 있다는 점을 한계로 기록하고, 최종 Test 평가 후 학습 데이터와 많이 닮은 사진과 덜 닮은 사진의 성능을 나눠 확인하기로 했습니다. 이때 최근접 사진의 라벨 일치율처럼 Test 성능을 미리 재는 계산은 Test를 한 번만 평가한다는 원칙에 맞춰 하지 않았습니다.
